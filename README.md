# Mounir Belboualia

Student in Data Science at Technische Hochschule Augsburg.

**Data Science · Machine Learning · Scientific Computing · Physics-Informed Modeling · MCP**

I work on research software that connects mathematical models, data analysis and reproducible evaluation. My interests include sensor time series, interpretable models and structured access to information.

## Research focus

- **Data science and machine learning:** explore data quality, compare baselines and evaluate models without data leakage.
- **Scientific computing and physics-informed modeling:** make assumptions explicit and distinguish mathematical derivations from experimental evidence.
- **Model Context Protocol (MCP):** explore tools that connect language models to structured, traceable information.

## Projects and interests

**Robot condition monitoring.** My research interests include physical and statistical reference models for robot sensor time series. A public reference dataset concerns the KUKA KR16 L6: [Sheffield ORDA dataset](https://doi.org/10.15131/shef.data.27368490.v1), by James Moore and Daniela Sawyer. This is an external dataset, not my own publication. Project code, reports and unpublished findings are not released here.

**Legali — private project.** Exploring structured access to German legal information through MCP. The implementation and configuration remain private.

## Working principles

- Keep software tests separate from scientific validation.
- Report limitations and negative findings alongside positive results.
- Track data provenance and credit external contributions, including AI assistance.
- Prefer simple, interpretable baselines before adding complexity.
